## Проверяемая команда baseline

После установки нативного ProVerif по официальной инструкции https://bblanche.gitlabpages.inria.fr/proverif/install.html из чистой рабочей копии:

```sh
cd upstream/FIDO2Verif
proverif -lib "FIDO2.pvl" Reg_unlink.pv
```

Это реальная команда README для P1 регистрации; в этом этапе **не выполнена**, успешное воспроизведение не заявлено. Не запускайте исходный Python-скрипт в каталоге с ценными LOG/TEMP/Result: он удаляет их даже при импорте или -h.
